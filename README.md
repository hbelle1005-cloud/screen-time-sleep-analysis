# Screen Time and Sleep Analysis

## Overview
This project explores the relationship between screen time before bed, bedtime, sleep quality, and next-day fatigue.

## Research Question
Does the timing of screen use influence its relationship with sleep quality?

## Methods
- Cleaned and selected relevant variables from the dataset.
- Grouped bedtimes into four two-hour intervals.
- Created scatter plots and regression lines to compare screen time and sleep outcomes across bedtime groups.

## Key Findings
- Screen time was associated with differences in sleep outcomes.
- Most relationships were relatively similar across bedtime groups.
- Deep sleep showed a different trend for the early bedtime group.

### Dataset

The dataset was downloaded from [Kaggle](https://www.kaggle.com/datasets/beamhonor0911/digital-insomnia-screen-habits-sleep) and included in this repository to keep the analysis reproducible. Since the original dataset may be updated over time, using a saved copy ensures that the results remain consistent with the version used for this project.
Dataset downloaded: October 2026.

## Limitations
This analysis identifies correlations, not causation. Other variables in the dataset may help explain the observed relationships.
